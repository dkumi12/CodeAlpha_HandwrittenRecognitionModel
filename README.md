# ✍️ Handwritten Character Recognition AI

This is a Convolutional Neural Network (CNN) model trained to recognize handwritten characters (A-Z, a-z, 0-9).

### How to use:
1. **Draw** a character on the canvas.
2. Click **Identify Character**.
3. The AI will tell you what you drew!
